# App name + icon concepts

01. **Teum · 틈** — 작은 공간에서 Mac의 흐름을 연결하는 도구
02. **Nori · 노리** — 친근하게 곁에 머무는 Mac 도우미
03. **Pico · 피코** — 작고 빠른 일상 도구
04. **Sway · 스웨이** — 제스처와 자연스러운 작업 흐름
05. **Luma · 루마** — 상태를 은은하게 알려주는 빛
06. **Halo · 헤일로** — 노치 주변으로 이어지는 활동
07. **Nesto · 네스토** — 여러 도구가 모이는 작은 둥지
08. **Pebble · 페블** — 작고 단단한 데스크 도구
09. **Veil · 베일** — 필요할 때만 보여주는 프라이버시
10. **Glint · 글린트** — 중요한 순간을 알려주는 반짝임

추천 검토 순서: 01 Teum, 02 Nori, 07 Nesto. 최종 순위는 이미지 검토 후 결정합니다.

Apple 앱 아이콘 가이드: https://developer.apple.com/design/human-interface-guidelines/app-icons
