## 사용 방법

1. **도구 직접 전환**: 메뉴 막대의 빠른 도구 또는 설정 → 빠른 도구 → 노치에서 도구 열기. 노치의 선택 메뉴에서 도구를 바꿉니다. `자동 활동으로 돌아가기`는 도구 활동만 닫고 기존 활동을 복구합니다. 일시적 시스템 알림은 기존 엔진 정책을 따릅니다.
2. **빠른 실행**: 앱에서 `⇧⌘K` 또는 메뉴의 빠른 실행. 도구와 저장된 메모를 검색합니다. `⌃⌥Space` 전역 단축키도 별도 등록하며 기존 타이머 단축키와 ID를 분리했습니다. 전역 키의 실제 키보드 동작은 별도 확인이 필요합니다. 앱 선택하여 열기는 사용자가 고른 앱만 실행합니다.
3. **집중 세션**: 집중 시간 선택 → 시작 → 완료 후 5분 휴식. 일시정지·재개·종료, 선택적 화면 잠자기 방지를 지원합니다. 완료 기록은 로컬 저장합니다. 실행 중 세션은 앱 종료 시 끝납니다.
4. **회의 입장**: 기존 달력 활동에서 시작까지 남은 시간과 입장 버튼을 사용합니다. 이벤트 URL뿐 아니라 메모·위치의 지원 서비스 HTTPS 링크도 찾습니다. 자동 입장은 하지 않습니다. 실제 일정 표시에는 달력 권한이 필요합니다.
5. **오늘 할 일 3개**: 날짜별로 최대 3개의 우선 작업을 추가·완료·제거합니다.
6. **이미지 변환**: 펼친 파일 트레이에서 지원 이미지의 우클릭 메뉴 → PNG 사본 또는 최대 1600px JPEG 사본 저장. 원본과 같은 경로는 거절합니다. JPEG의 투명 배경은 흰색으로 처리합니다. 이미지/다중 프레임 소스의 첫 이미지만 정적 파일로 내보냅니다.
7. **직접 저장한 클립보드**: 저장 버튼을 누를 때만 현재 일반 텍스트를 읽습니다. 암호 관리자가 숨김 표시한 항목은 제외합니다. 자동 감시 없음. 항목별 복사·제거, 최대 100개·항목당 100KB. JSON은 0600 파일이며 암호화되지는 않습니다.
8. **앱별 표시 규칙**: 앱 선택 → 해당 앱이 맨 앞에 있을 때 노치 숨김. 규칙을 제거하면 자동 표시로 돌아갑니다. 앱 번들 ID를 정확히 비교하며 DynamicNotch 자체는 제외합니다.
9. **작업 실행·결과**: 프로젝트와 공유 Scheme 이름을 선택해 Xcode 빌드를 시작하거나 선택 파일의 SHA-256을 계산합니다. 셸 명령 입력은 지원하지 않습니다. 실제 종료 코드·소요 시간·최근 출력과 중단 요청을 제공합니다. 선택 프로젝트의 빌드 스크립트가 실행된다는 설명을 표시합니다. 빌드 산출물은 별도 캐시 디렉터리에 생성합니다.
10. **권한·리소스 상태**: 카메라·달력·손쉬운 사용 권한, 선택적 연결 수, 감시 폴더, 잠자기 방지 상태를 확인합니다. 권한 요청 없이 조회하며, 잠자기 방지 해제·선택적 연결 끄기·미디어/다운로드/녹화/타이머 감시 중지를 제공합니다. 이미 전송된 네트워크 요청은 완료될 수 있습니다.

## 저장과 검증

메모는 기존 quick-notes.json, 새 할 일·클립보드·집중 완료 기록·앱 규칙은 Application Support/DynamicNotch/productivity.json에 저장합니다. 손상되거나 지원하지 않는 스키마의 파일은 덮어쓰지 않고 오류를 표시합니다. 기존 메모 초안은 팔레트 검색으로 다른 메모를 선택해도 자동 덮어쓰기 하지 않습니다.

자동 테스트 244개와 집중 모델 테스트 14개가 통과했습니다. 실제 설치본에서 팔레트, 도구 전환, 1분 집중 완료·휴식, 할 일 저장·완료, 검증용 클립보드 저장, SHA-256 성공 출력과 상태판을 확인했습니다. 실제 회의 입장, 파일 트레이에서 드래그 후 변환 저장, 다른 앱이 맨 앞일 때 숨김 및 전역 단축키 실키보드 입력은 아직 별도 수동 검증 대상입니다. 구현·빌드·단위 테스트·수동 검증을 같은 상태로 취급하지 않습니다. 자세한 명령과 실패 수정 이력은 TEST_REPORT.md 참조.

기존 자동 스크린샷 가로채기는 데스크탑을 읽고 macOS 캡처 설정을 변경하므로 로컬 빌드에서 비활성화했습니다. 해당 설정 화면에 설명을 표시하며 화면 녹화 활동 감지는 별도 유지합니다. 이전 macOS 설정 값을 추측해 덮어쓰지 않습니다.
