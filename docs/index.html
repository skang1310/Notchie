Notchie — 나만의 맞춤형 macOS 노치 워크스페이스

유휴 노치에 마우스를 올리면 열리는 NotchNook 스타일 호버 메뉴, 실시간 클립보드 히스토리 검색 및 원클릭 재복사, 카메라 얼굴 잠금 해제 (오리지널 풀 배지 스캔 & 미니멀 프리뷰), 맞춤 강조 색상 피커, 그리고 앱 시작 시 필수 권한 자동 점검 및 알림을 하나로 결합한 오픈소스 커스텀 앱입니다.

주요 커스텀 기능 (Key Features)

오픈소스 기반 위에 일상 생산성과 개인화 경험을 극대화하도록 설계된 핵심 기능들입니다.

🧲 노치 호버 메뉴 & 맞춤 탭 (Hover Shelf)

라이브 액티비티가 없을 때도 상단 노치에 마우스를 올리면(Hover) 즉시 허브 메뉴가 펼쳐집니다. 원하는 도구 탭만 골라 켜고 끌 수 있으며, 고정(Pin) 버튼으로 작업 중 노치 창을 유지할 수 있습니다.

📋 클립보드 히스토리 검색 & 원클릭 복사

복사한 텍스트 내역을 검색창에서 실시간으로 필터링하고, 항목이나 복사 버튼을 클릭해 원클릭으로 재복사(`Copied!` 피드백)합니다. 비밀번호 등 민감 타입을 제외한 선택적 자동 기록(Auto-capture) 옵션을 지원합니다.

🪪 얼굴 잠금 해제: 오리지널 배지 vs 미니멀 미리보기

HeyMac 엔진을 통합하여 카메라 기반 얼굴 잠금 해제와 앱 프라이버시 가림막을 제공합니다. 오리지널 (풀 배지 스캔 애니메이션)과 미니멀 (자물쇠 + 스캔 바) 스타일을 나란히 비교하고 실제 노치에서 즉시 미리볼 수 있습니다.

🎨 커스텀 강조 색상 (Accent Color) & 테마

8종의 프리셋 컬러칩과 macOS 기본 ColorPicker로 나만의 강조 색상(HEX)을 지정할 수 있습니다. 선택한 색상은 노치 호버 탭, 얼굴 스캔 애니메이션, 상태 배지에 실시간 반영됩니다.

🛡️ 시작 시 권한 자동 확인 및 미설정 알람

앱 시작 시 손쉬운 사용(Accessibility), 카메라, 캘린더, 블루투스, 미디어 제어 등 필수 권한을 확인·요청합니다. 설정되지 않은 권한이 있으면 노치 배너 및 경고 알람을 띄워 권한 설정 페이지로 바로 안내합니다.

✨ Notchie 전용 Light/Dark 아이콘 & 클린 UI

macOS Light 및 Dark 테마에 맞춘 전용 Notchie 아이콘 세트를 전면 적용하고, 불필요한 후원 및 외부 자동 업데이트 페이지를 제거하여 깔끔한 독립형 워크스페이스로 다듬었습니다.

빌드 및 로컬 설치 (Build & Install)

Xcode 커맨드라인 도구로 테스트, 릴리즈 빌드 및 /Applications 설치를 진행할 수 있습니다.

# 1. 단위 테스트 실행 (서명 불필요)
xcodebuild -project DynamicNotch.xcodeproj \
  -scheme DynamicNotch \
  -destination 'platform=macOS' \
  -derivedDataPath build/DerivedData \
  CODE_SIGNING_ALLOWED=NO test

# 2. Release 빌드 및 /Applications 설치
xcodebuild -project DynamicNotch.xcodeproj \
  -scheme DynamicNotch \
  -configuration Release \
  -derivedDataPath build/DerivedData \
  CODE_SIGNING_ALLOWED=NO build

./scripts/install-local.sh
